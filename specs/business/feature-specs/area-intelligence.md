# Feature: Area Intelligence

## Purpose

Help users evaluate Dubai/UAE areas as investment zones.

This feature should make it easy to understand which areas appear attractive for property investment.

## User Value

Users can:

- Browse investment areas.
- Compare area-level metrics.
- Understand demand, risk, yield, and appreciation potential.
- Open area details before looking at individual properties.
- Save areas to the watchlist.

## Main User Actions

- View list of areas.
- Search or filter areas if included in a task.
- Open area details.
- Save or remove area from watchlist.
- View properties inside an area.
- Compare area metrics visually.

## Displayed Information

Area list may show:

- Area name
- Average property price
- Average rent
- Average rental yield
- Demand level
- Risk level
- Investment score

Area details may show:

- Market summary
- Average price per sqft
- Average rental yield
- Rent trend
- Price trend
- Demand level
- Risk level
- Appreciation potential
- Nearby lifestyle/business factors
- Related properties
- AI insight

## Business Rules

- Area metrics are estimates.
- Area names should be realistic.
- Risk level must be one of: Low, Medium, High.
- Demand level must be one of: Low, Medium, High.
- Investment score must be between 0 and 100.
- Area details should focus on investment attractiveness.
- Area intelligence must not claim guaranteed future appreciation.
- Areas can be saved to the watchlist.

## Acceptance Criteria

- User can view a list of areas.
- User can open an area details screen.
- User can understand the area's investment attractiveness.
- User can see key metrics such as yield, demand, risk, and score.
- User can save or unsave an area if watchlist functionality is included.
