# Feature: Property Comparison

## Purpose

Allow users to compare multiple properties side by side using investment metrics.

## User Value

Users can:

- Compare opportunities objectively.
- See which property has better yield.
- Compare price, rent, risk, and score.
- Avoid relying only on property appearance or location name.
- Make better shortlisting decisions.

## Main User Actions

- Add property to comparison.
- Remove property from comparison.
- View comparison table or cards.
- Compare key metrics.
- Open property details from comparison.
- Clear comparison list.

## Compared Metrics

Comparison may include:

- Property price
- Area
- Size
- Price per sqft
- Expected annual rent
- Gross rental yield
- Net rental yield
- Service charges
- Annual costs
- Monthly cash flow
- Demand level
- Risk level
- Investment score
- Appreciation potential

## Business Rules

- Comparison should focus on investment metrics.
- At least two properties are needed for meaningful comparison.
- The app may allow comparison of up to four properties in the demo.
- Comparison must not declare a guaranteed winner.
- If highlighting the best value in a column, the logic must be clear.
- Different metrics may point to different conclusions.
- Risk must be shown alongside return.

## Acceptance Criteria

- User can add at least two properties to comparison.
- User can view selected properties side by side.
- User can remove a property from comparison.
- User can compare return and risk metrics.
- User can open property details from comparison.
