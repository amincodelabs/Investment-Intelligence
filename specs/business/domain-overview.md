# Domain Overview

## Domain

The app belongs to the real estate investment analysis domain.

The domain combines:

- Real estate market information
- Property-level financial metrics
- Area-level market intelligence
- Investment calculation
- Risk evaluation
- User preference tracking

## Core Domain Concepts

The main business concepts are:

- User
- Account
- Property
- Area
- Investment Metrics
- Investment Score
- Rental Yield
- Net Rental Yield
- Cash Flow
- Market Trend
- Watchlist
- Comparison
- Investment Assumption
- Risk Level

## Main Domain Flow

A typical user journey:

1. User opens the app.
2. User views market summary on the dashboard.
3. User explores investment areas.
4. User opens an area details page.
5. User reviews properties in that area.
6. User opens a property details page.
7. User reviews investment metrics.
8. User uses the calculator to test assumptions.
9. User compares the property with alternatives.
10. User saves interesting properties or areas to the watchlist.

## Important Domain Boundary

The app analyzes investment opportunities.

The app does not perform property transactions.

The app does not provide regulated financial advice.

The app does not verify legal ownership, title deed status, developer obligations, or government approvals in the demo version.

## Data Assumption

For the demo version, all business data may be mocked.

However, mock data must be internally consistent.

Example:

If a property price is 1,000,000 AED and expected annual rent is 80,000 AED, the gross rental yield should be 8%.

The app should not show random metrics that contradict each other.
